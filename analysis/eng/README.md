# 後中英文：歷屆試題試驗分析

目的：在投入製作英文課程前，先用少量近年試題確認兩件事：題型是否固定、單字與文章範圍是否有限。範圍太大就改用別的方法。

範圍（試驗）：中國醫藥（cmu）114、115；慈濟（tcu）114、115；義守（isu）113、114（網站未放 115），共 6 份。
試題來源：https://www.3dollars.com.tw/Hce/test_questions.html （中國醫、慈濟為各年壓縮檔，內含各科 PDF，檔名為 Big5；義守為單一 PDF 含各科）。
試卷只放在本機 `papers/`（不進 git，有著作權）；本資料夾只保存統計與結論。

## 檔案
- `analyze.py`：字彙題選項的詞頻分布、整卷用字覆蓋率、各卷難字重複率，輸出 `result.txt`。需要 `wordfreq`（見檔頭說明）。
- `papers/*.txt`：以 `pdftotext -layout` 轉出的英文卷文字；義守只保留英文科的頁面。

## 方法與限制
- 詞頻用 wordfreq 的英文「詞形」排名（inflected form，非字族），去掉常見字尾、拆開連字號複合字取最難的部分、略過專有名詞。排名比字族排名大約多一倍，所以數字只看相對大小與趨勢。
- 「難字」＝排名 8000 以後的詞形；重複率＝在其他 5 份中出現過的比例。

## 結果（2026-10-31）

### 一、題型：三校固定，且大部分分數可以拆步教
- 每份 50 題單選。
- 中國醫：字彙 10–15、克漏字 10–20、閱讀 15–20；114 年另有「段落填句」10 題。答錯倒扣 0.7 分。
- 慈濟：字彙 15、克漏字 15、閱讀 20。
- 義守：字彙與用法 15、文法 10、克漏字 10、閱讀 13–15。
- 克漏字、閱讀、文法約佔 35–40 題（七到八成），解題步驟固定：找句子主幹 → 看空格前後的邏輯 → 回原文定位 → 判斷是否為換句話說。

### 二、字彙題：範圍太大，不追
- 選項大多是排名 2 萬以後的罕見字（GRE 程度，如 obsequious、prevaricate、laconic、parsimonious、insouciance）。
- 各卷難字只有 15–25% 在其他卷出現過，背考古題單字幾乎無法覆蓋下一次考試。
- 策略：只答有把握的；中國醫倒扣，看不懂就留空。

### 三、文章用字與主題
- 認得前 8000 個詞形時，覆蓋率約 85–90%；要到 95% 需要約 1.6–2.4 萬個詞形，明顯超過高中 7000 字。
- 讀不懂的主要是學術常用字與醫學字根，比字彙題的罕見字有限得多。
- 主題約一半是醫學與健康（癌症風險因子、HIIT 與減脂、GLP-1 藥物、憂鬱症醫學史、新生兒語言），其餘為經濟、國際政治、神話、運動員報導等。

## 結論
- 「一步一步來」可以用在克漏字、閱讀、文法（大部分分數）；不適用於字彙題。
- 單字改為「讀懂文章需要的字」：學術常用字＋醫學字根，不追罕見字。
- 下一步：做一個試做單元（長句拆解、醫學字根、克漏字、閱讀，各題附拆解步驟），實際試用後再決定是否擴大到 10 年三校的完整分析與課程。
