# 後中國文：近兩年試題分析

目的：決定國文每週練習題的題型、比例與難度（2026-11-08 使用者要求「仿照英文，檢查近兩年三間學校的國文考卷」）。

範圍：中國醫藥（cmu）、慈濟（tcu）、義守（isu）114、115 學年度國文試題，共 6 份、300 題。
試題來源：https://www.3dollars.com.tw/Hce/test_questions.html （中國醫、慈濟為各年壓縮檔，內含各科 PDF，檔名為 Big5；義守為單一 PDF 含各科，國文在最前面）。
試卷只放在本機 `papers/`（不進 git，有著作權）；本資料夾只保存統計與結論。

## 一、題型：三校相同
- 每份 50 題四選一單選，沒有作文、沒有多選。
- 倒扣：中國醫、慈濟每題 0.7 分；義守每題 0.5 分。

## 二、各類題目每份約幾題
中國醫 114 逐題分類，其餘 5 份依題幹粗分，數字是約數。

| 類別 | 每份約 | 常見考法 |
|---|---|---|
| 閱讀題組 | 18–22 | 古文、詩詞、白話文、新詩，一篇 2–5 題；問主旨、詮釋、寫作手法、詞義 |
| 字詞 | 8–10 | 字義前後是否相同、詞性、量詞、成語使用正誤、成語意涵分類 |
| 國學與文化常識 | 8–10 | 用典、代稱（金烏、尺素、雙鯉魚）、干支紀年、題辭與對聯、六書、數字虛實、作家作品、節令 |
| 字音字形 | 7–9 | 讀音是否相同、錯別字、贅字 |
| 修辭、排序、填空 | 5–6 | 激問、層遞、頂真、代語；文句排序；依文意填詞 |

## 三、後中特色
- 三校都有中醫典籍或醫學文章：《黃帝內經》《千金要方》《金匱要略》、藥名詩（陳亞〈生查子〉）、葉天士〈四季歌〉、嗜鹽菌食物中毒說明文。
- 古文多出自《論語》《孟子》《莊子》《左傳》《史記》《世說新語》與唐宋古文；詩詞以唐宋為主；現代詩文有余光中、楊牧、鄭愁予、王鼎鈞等。
- 選項常用「何者兩兩相同」「何者不正確」「最不適當」，誤答多是常見混淆（同音字、近義成語、詞性活用）。

## 四、練習題的做法（2026-11-08 與使用者確認）
- 照英文：每週 7 天、每天早晚兩段。份量先用輕量版：每天約 15 題、30 分鐘（早上字音字形、字詞、常識 8 題；晚上閱讀 7 題：一篇古文或醫古文題組、一首詩詞或白話文、兩題排序／填空／修辭）。
- 題目全部自擬；引文只用公版古籍與古典詩詞，現代文章改用自擬短文或短詩。
- 讀音依教育部《重編國語辭典修訂本》。
- 每題的解析逐一說明四個選項（ex），閱讀題附文中根據（ref）；不用「一步一步來」與追問（2026-11-10 使用者要求，國文不像英文能用文法推理）。答錯進共用的錯題排程（src/shared/review.js）。
